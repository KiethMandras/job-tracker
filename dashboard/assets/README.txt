Put your own original artwork here. The dashboard picks these up automatically:

  banner.jpg   wide cover image for the top of the page (about 1600 x 360)
  avatar.png   square profile picture

Accepted formats: jpg, jpeg, png, webp, gif. Images are shown in black and white.
Without these files, the dashboard draws its own ink-and-halftone skyline banner
and shows your initials. Set DASHBOARD_INITIALS in .env to change the initials.

Please use only artwork you made or have the right to use.
